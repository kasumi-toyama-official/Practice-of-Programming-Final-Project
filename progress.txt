一、项目概述
────────────────────────────────────────────────────────────────────────────────
本项目是一个基于 C++ 和 Qt 框架的答题战斗游戏（教育 RPG），
玩家通过答对 C++ 知识题来攻击敌人，推进章节，解锁成就。

代码仓库: Practice-of-Programming-Final-Project
许可协议: MIT License
开发状态: 后端核心层 + 前端 UI 层均已实现，前后端尚未对接

三、各层功能详解
────────────────────────────────────────────────────────────────────────────────

【数据模型层 — models/】
  7 个数据模型，均为纯 struct（非 QObject），自带 toJson() / fromJson()。
  ┌────────────────────┬──────────────────────────────────────────────────┐
  │ Achievement        │ 成就 ID、名称、描述、分类(学习/战斗)、图标路径、解锁状态 │
  │ ChapterArchive     │ 章节存档：玩家状态、敌人状态、配置、已用题目ID、回合数  │
  │ EnemyState         │ 敌人属性：名称、血量、攻击、防御、固定伤害             │
  │ GameConfig         │ 权重配置：简单/中等/困难权重、选择/填空/代码权重       │
  │ PlayerState        │ 玩家属性：血量、攻击、防御、吸血比例 + buff/heal 方法  │
  │ Question           │ 题目：ID、章节、难度、类型、题干、4选项、答案、解析    │
  │ WrongBookEntry     │ 错题：章节ID、题目ID、时间戳、错误次数               │
  └────────────────────┴──────────────────────────────────────────────────┘

【业务管理层 — managers/】
  4 个管理类，负责游戏核心逻辑，通过 JsonUtils 进行持久化。
  ┌────────────────────┬──────────────────────────────────────────────────┐
  │ AchievementManager │ 从 JSON 加载成就定义/进度，解锁成就，分章检查战利品 │
  │ ConfigPresetManager│ 管理多套难度预设（增删改查），JSON 存取            │
  │ QuestionBank       │ 加载各章题库，加权随机抽题，排除已用题目，单题查询  │
  │ SaveManager        │ 章节存档 CRUD，扫描目录判断哪些章节有存档可继续   │
  └────────────────────┴──────────────────────────────────────────────────┘

【工具层 — utils/】
  2 个命名空间，提供无状态工具函数。
  ┌────────────────────┬──────────────────────────────────────────────────┐
  │ JsonUtils          │ readJsonObject/Array, writeJsonObject/Array,     │
  │                    │ ensureDirectoryExists                           │
  │ RandomUtils        │ initSeed, randomInt (均匀), weightedRandom (加权)│
  └────────────────────┴──────────────────────────────────────────────────┘

【UI 层 — 前端界面】
  采用 Qt Widgets + Qt Designer（.ui 文件），960x640 固定窗口，页面式导航。
  ┌────────────────────┬──────────────────────────────────────────────────┐
  │ MainWindow         │ 顶层窗口，固定 960x640，将容器交给 UIManager     │
  │ UIManager          │ 导航单例：8页面注册、滑动动画、历史栈、返回功能   │
  │ MainMenuPage       │ 主菜单：学习模式/竞技场/错题本/收藏/成就/设置   │
  │ ChapterSelectPage  │ 章节选择（占位，仅返回按钮）                     │
  │ BattlePage         │ 核心战斗：学习模式（回合制）和竞技场（限时生存） │
  │   StatusBar        │ HUD：双方血量/攻防/吸血/增益/回合数/通行证     │
  │   QuestionWidget   │ 三题型组件：选择（4按钮）、填空（输入框）、代码   │
  │   SkillPanel       │ 技能选择：网格布局、难度选择、淡入淡出动画       │
  │ ResultPage         │ 战斗结算（占位，仅返回按钮）                     │
  │ ErrorBookPage      │ 错题回顾（占位，仅返回按钮）                     │
  │ CollectionPage     │ 收藏图鉴（占位，仅返回按钮）                     │
  │ AchievementPage    │ 成就展示（占位，仅返回按钮）                     │
  │ SettingsPage       │ 游戏设置（占位，仅返回按钮）                     │
  └────────────────────┴──────────────────────────────────────────────────┘
